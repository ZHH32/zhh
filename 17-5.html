JavaScript 定时器 · setTimeout / setInterval

张淮皓的JavaScript · 一次性倒计时 vs 循环定时，形象对比两种定时器的用法与清除

一次性定时器

setTimeout() · 只执行一次

var zhh_id = setTimeout(function () { console.log("时间到！"); }, 3000); // 3 秒后执行一次 clearTimeout(zhh_id); // 取消定时器
延迟： 秒
3.0
定时器 ID：—
状态：未启动
循环定时器

setInterval() · 每隔一段时间重复执行

var zhh_id = setInterval(function () { console.log("滴答"); }, 1000); // 每 1 秒执行一次 clearInterval(zhh_id); // 停止循环
00:00:00
定时器 ID：—　已触发 0 次
对比与注意

两种定时器的区别

setTimeoutsetInterval
执行次数1 次多次（每隔间隔）
清除方法clearTimeout(id)clearInterval(id)
返回值定时器 ID（数字）定时器 ID（数字）
典型用途倒计时、延迟跳转、防抖时钟、轮询、动画
注意：
1. 定时器返回的是一个 ID（数字），不用时要 clearTimeout / clearInterval，否则会一直占用内存或重复执行。
2. setInterval 不保证精确，如果回调执行时间超过间隔会堆积；更稳的做法是用递归 setTimeout。
3. 定时器回调里的 this 默认指向 window，箭头函数可保留外层 this。
