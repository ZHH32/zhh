JavaScript 对象 · 形象演示

张淮皓的JavaScript · 把对象想成一张「个人档案卡」，属性是卡片上的条目，方法是卡片主人会做的事

对象档案卡 · 实时舞台

下面这张卡片就是对象 zhh_person，每一行「属性名: 属性值」就是它的一个属性

点击下方任意按钮，这里会显示执行的代码和结果
读取属性

点语法 / 中括号语法

zhh_person.name → 点语法取值，最常用 zhh_person["name"] → 中括号语法，键名要加引号 zhh_person.age → 属性值也可以是数字
两种写法效果一样，中括号里可以放变量，点语法不行
增删改属性

添加 / 修改 / delete

zhh_person.city = "北京" → 档案卡上新增一行 zhh_person.age = 21 → 已有的条目直接改值 delete zhh_person.city → 把这一行从卡片上划掉
对象像一张可以随时涂改的档案卡，增删改都很自由
方法与 this

对象里的函数 · 方法

zhh_person.sayHi = function () { return "大家好，我是" + this.name; } this 就代表「当前这张档案卡」自己
方法就是对象里保存的函数，this 指向对象本身
遍历与工具

for...in / Object.keys / values

for (var zhh_k in zhh_person) { … } → 逐行念档案 Object.keys(zhh_person) → 拿到所有属性名的数组 Object.values(zhh_person) → 拿到所有属性值的数组
for...in 一次拿到一个属性名，工具方法批量拿属性名或属性值
