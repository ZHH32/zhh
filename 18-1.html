Canvas 动画 · 张淮皓

张淮皓的JavaScript · 用原生 Canvas API 做三种动画，主角文字都是「张淮皓」

粒子文字

粒子拼成「张淮皓」

移动鼠标可以推开粒子，鼠标移开后粒子重新聚拢成文字

渐变描边

渐变脉冲文字

createLinearGradient 配合 sin 缩放，让文字颜色与大小一起呼吸

文字雨

「张淮皓」文字雨

每列不断下落，颜色随机，类似代码雨效果

核心 API

本页用到的 Canvas API

getContext('2d') 获取 2D 绘图上下文 fillText / strokeText 填充 / 描边文字 createLinearGradient 创建线性渐变 getImageData 读取像素（粒子文字用它采样文字轮廓） clearRect 清空画布（每帧重绘前调用） requestAnimationFrame 浏览器刷新率驱动动画循环 arc / fillRect 画圆点 / 矩形粒子
