Web 前端的长度单位

张淮皓的《高级网页设计》课堂实践 —— CSS 长度单位一览

1. 绝对单位 px

像素（pixel），最常用的绝对单位。不随父元素或视口变化，大小固定。

width: 200px; height: 60px;

200px × 60px

2. 相对单位 em

相对于当前元素（或父元素）的 font-size。常用于 padding、margin，实现随字体缩放的弹性布局。 例：父元素 font-size: 20px，则 1.5em = 30px。

父元素 font-size: 20px; 子元素 width: 10em; height: 3em; font-size: 18px

10em × 3em

当前文字：1.5em = 30px（随父级字体变化）

3. 相对单位 rem

root em，相对于根元素（html）的 font-size（默认 16px）。 不受父级字体影响，全站统一缩放，适合响应式布局。 例：8rem = 8 × 16px = 128px。

width: 8rem; height: 3rem;

8rem × 3rem

提示：浏览器默认 html 的 font-size 为 16px。

4. 相对单位 %

相对于父元素对应属性的值。宽度的 50% 即父元素宽度的一半。

width: 50%; height: 40px;（相对上方容器宽度）

宽度的 50%

5. 视口单位 vw / vh

相对于浏览器视口（viewport）： vw = 视口宽度的 1%，vh = 视口高度的 1%。 窗口缩放时元素自动跟随变化，适合全屏布局与响应式排版。

width: 20vw; height: 40px;（随窗口宽度变化）

20vw

width: 60px; height: 12vh;（随窗口高度变化）

12vh

试着拖动浏览器窗口大小，观察这两个色块的变化。

6. 视口单位 vmin / vmax

vmin = 视口宽、高中较小值的 1%；vmax = 较大值的 1%。 常用于保证元素在横屏/竖屏下都保持比例。

width: 15vmin; height: 15vmin;

15vmin

7. 单位速查表

单位名称相对基准典型用途
px像素绝对（固定）边框、固定尺寸
em字高父元素 font-sizepadding、行内弹性间距
rem根字高html 的 font-size响应式字号、间距
%百分比父元素尺寸流式布局宽度、高度
vw视口宽 1%浏览器窗口宽度全屏区块、大标题
vh视口高 1%浏览器窗口高度整屏容器高度
vmin视口较小边 1%视口短边正方形自适应元素
vmax视口较大边 1%视口长边横竖屏自适应

8. 实践建议

· 移动端优先用 rem 做全局字号，方便整体缩放；
· 组件内部间距用 em，字号变时间距跟着变；
· 全屏首屏用 100vh（注意移动浏览器地址栏问题）；
· 流式布局用 %，固定细节用 px。
