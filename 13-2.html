Lucide SVG 图标

张淮皓的《高级网页设计》课堂实践 —— SVG 图标（SVG Icon）

1. 什么是 SVG 图标

SVG 图标是用 <svg> 矢量图形描述的图标：每个图标就是一段 XML 标记（路径、圆形、描边等）， 可以直接内联到 HTML 中。因为是真正的矢量图形，它任意缩放都清晰， 并且可以用 CSS 自由控制 stroke（描边）、fill（填充）、stroke-width（粗细）等属性。

本页面使用 Lucide 图标库（当前版本 1.59.0）。它的官方用法是通过 JS 把 <i data-lucide="图标名"> 这样的占位元素在运行时替换为内联 SVG， JS 文件已下载到本地 cdn/lucide.min.js。

2. 引入与使用

① 引入本地 JS：<script src="cdn/lucide.min.js"></script>
② 声明式使用：<i data-lucide="house"></i>
③ 执行 lucide.createIcons() 后，占位元素被替换为真实的 <svg> 标签。 也可以传入全局属性，如 lucide.createIcons({ attrs: { 'stroke-width': 1.5 } })。

data-lucide="house" → <svg>

data-lucide="rocket"

6. 颜色与描边控制

Lucide 图标默认 stroke="currentColor"，描边颜色自动继承文字颜色 color； stroke-width 控制描边粗细（占位元素上的属性会原样传给生成的 SVG）：

color:#f87171
color:#60a5fa
color:#34d399
color:#fbbf24
color:#c084fc
stroke-width:1
stroke-width:1.5
stroke-width:2
stroke-width:3

8. 内联 SVG 代码

lucide.createIcons() 执行后，<i data-lucide="house"> 会被替换为下面这段真实的 SVG 标记。 这意味着图标就是页面 DOM 的一部分，可以用任意 CSS/JS 操作：

<svg xmlns="http://www.w3.org/2000/svg" width="24" height="24" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" class="lucide lucide-house"> <path d="M15 21v-8a1 1 0 0 0-1-1h-4a1 1 0 0 0-1 1v8"/> <path d="M3 10a2 2 0 0 1 .709-1.528l7-5.999a2 2 0 0 1 2.582 0l7 5.999A2 2 0 0 1 21 10v9a2 2 0 0 1-2 2H5a2 2 0 0 1-2-2z"/> </svg>

9. SVG 图标 vs 字体图标

同课程的 13-1.html 演示了 Font Awesome 字体图标方案，对比如下：

对比项 SVG 图标（Lucide） 字体图标（Font Awesome）
实现原理 矢量图形标记，内联到 DOM 图标是字体字形，CSS 类名渲染
大小控制 width / height 属性或 CSS font-size / fa-2x 等尺寸类
颜色控制 stroke / fill / stroke-width，可多色 color 属性（单色系）
动画能力 CSS / SMIL 自由定制，需自写 内置 spin / bounce 等丰富动画
加载方式 JS 内联渲染，无字体请求 需加载字体文件，首次有 FOUT 风险
清晰度 矢量任意缩放清晰 受字体渲染影响，小尺寸可能发虚
