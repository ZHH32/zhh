ECharts 折线图演示

张淮皓的JavaScript · 基础折线图 vs 平滑折线图，使用本地 echarts.min.js

基础折线图

基础折线图（Line Chart）

type: 'line'，折线为直线段连接，数据点用默认标记显示

series: [{ data: [150, 230, 224, 218, 135, 147, 260], type: 'line' // 直线段连接 }]
平滑折线图

基础平滑折线图（Smooth Line）

smooth: true，折线变为贝塞尔曲线，视觉更柔和

series: [{ data: [820, 932, 901, 934, 1290, 1330, 1320], type: 'line', smooth: true // 曲线平滑 }]
