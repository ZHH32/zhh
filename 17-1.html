数据类型

JSON 只有六种值

字符串 string
"前端"
数字 number
20
布尔 boolean
true
空值 null
null
数组 array
[1, 2]
对象 object
{ }
JSON 不支持函数、undefined、日期、单引号字符串，这些都是 JS 才有的
语法对比

JSON ≠ JavaScript 对象

// ❌ JS 对象写法（键可不加引号，可有函数） var zhh_o = { name: "张淮皓", age: 20, say: function(){ } }; // ✅ 合法 JSON（键必须双引号，无函数、无尾逗号） { "name": "张淮皓", "age": 20 }
JSON 是纯文本格式，键名必须用双引号、不能有尾随逗号、值不能是函数或 undefined
字符串 → 对象

JSON.parse() · 把文字读成数据

var zhh_s = '{"name":"张淮皓","age":20,"vip":true}'; var zhh_obj = JSON.parse(zhh_s); // 现在 zhh_obj.name 就能取到 "张淮皓"
对象 → 字符串

JSON.stringify() · 把数据写成文字

var zhh_data = { name:"张淮皓", hobby:["前端","音乐"] }; JSON.stringify(zhh_data) // 压缩成一行 JSON.stringify(zhh_data, null, 2) // 缩进 2 格，便于阅读
