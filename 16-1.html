数组小火车 · 实时舞台

下面每一节「车厢」就是数组的一个元素，车厢号就是下标（从 0 开始）

点击下方任意方法按钮，这里会显示执行的代码和结果
增删元素

push / pop / unshift / shift

zhh_arr.push("菠萝") → 车尾加一节车厢 zhh_arr.pop() → 车尾摘掉一节车厢 zhh_arr.unshift("草莓") → 车头加一节车厢 zhh_arr.shift() → 车头摘掉一节车厢
从车尾或车头增加、删除元素，都会直接改变原数组
查找与截取

indexOf / includes / slice / splice

zhh_arr.indexOf("香蕉") → 找下标，找不到返回 -1 zhh_arr.includes("西瓜") → 是否存在，返回 true/false zhh_arr.slice(1, 3) → 复制一段，原数组不变 zhh_arr.splice(1, 1) → 从下标1删除，原数组改变
slice 像「复印」，splice 像「剪断」
排序与转换

join / reverse / sort

zhh_arr.join(" → ") → 把数组拼成一串文字 zhh_arr.reverse() → 整列火车掉头 zhh_arr.sort() → 按默认顺序排队
join 只生成字符串不改变数组，reverse 和 sort 会改变原数组
高阶方法

forEach / map / filter / reduce

var zhh_nums = [3, 8, 12, 5, 20]; forEach → 逐个报数（遍历一遍） map → 每个数都 ×2，得到新数组 filter → 挑出大于 9 的数 reduce → 把所有数加成一个总和
这些方法都不会改变原数组，map / filter 会返回新数组
