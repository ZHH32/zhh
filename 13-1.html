Font Awesome 字体图标

张淮皓的《高级网页设计》课堂实践 —— 字体图标（Font Icon）

1. 什么是字体图标

字体图标是把图标做成一个字体文件：每个图标对应字体中的一个字形（glyph）， 通过 @font-face 引入字体，再用 CSS 类名把图标"字符"渲染出来。 它本质上和文字一样，所以可以用 font-size 控制大小、用 color 控制颜色， 还能享受文字的抗锯齿效果。

本页面使用 Font Awesome 6 Free，CSS 与字体文件已下载到本地 cdn/ 目录： cdn/css/all.min.css + cdn/webfonts/fa-*.woff2。

2. 引入方式

① 在 <head> 中引入本地 CSS： <link rel="stylesheet" href="cdn/css/all.min.css">
② CSS 会通过相对路径自动加载同级的 cdn/webfonts/ 字体文件，无需额外配置。

引入成功即代表字体加载成功

3. 基础用法：图标网格

在元素上添加两个类：样式类（fa-solid 实心 / fa-regular 常规 / fa-brands 品牌） + 图标类（fa-图标名），例如 <i class="fa-solid fa-house"></i>。

6. 旋转与动画

Font Awesome 内置了多种动画类：fa-spin 旋转、fa-pulse 脉冲、fa-beat 心跳、 fa-bounce 弹跳、fa-shake 抖动、fa-flip 翻转，以及静态旋转 fa-rotate-90/180/270。

7. 定宽图标与列表

fa-fw（fixed width）让所有图标占据相同宽度，适合按钮和导航； fa-ul + fa-li 可以把图标作为列表项目符号，替代默认的圆点。

fa-fw 定宽对齐
  • 字体图标加载成功
  • 支持 font-size 控制大小
  • 支持 color 控制颜色
  • 支持内置动画效果
fa-ul 图标列表

9. 字体图标 vs SVG 图标

同课程的 13-2.html 演示了 Lucide 的 SVG 图标方案，对比如下：

对比项 字体图标（Font Awesome） SVG 图标（Lucide）
实现原理 图标是字体字形，CSS 类名渲染 矢量图形标记，内联或 sprite 引用
大小控制 font-size / fa-2x 等尺寸类 width / height 属性或 CSS
颜色控制 color 属性（单色系） stroke / fill（currentColor），可多色
动画能力 内置 spin / bounce 等丰富动画 依赖 CSS / SMIL，灵活但需自写
加载方式 需加载字体文件，首次有 FOUT 风险 内联无请求；sprite 需一次请求
清晰度 受字体渲染影响，小尺寸可能发虚 矢量任意缩放清晰
